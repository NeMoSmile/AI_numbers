# Digit Classifier (MNIST) from Scratch

Простая полносвязная нейронная сеть для распознавания рукописных цифр, написанная **с нуля на чистом Python и NumPy** (без использования PyTorch или TensorFlow).

## 🧠 О нейросети

* **Архитектура:** 3 слоя (Входной -> Скрытый -> Выходной).
  * **Входной слой:** 784 нейрона (изображение цифры 28x28 пикселей, вытянутое в вектор).
  * **Скрытый слой:** 300 нейронов с функцией активации **ReLU**.
  * **Выходной слой:** 10 нейронов (цифры от 0 до 9) с функцией **Softmax со сдвигом** (защита от ошибок переполнения памяти `NaN`).
* **Датасет:** Официальный MNIST (60 000 картинок для обучения, 10 000 для теста).
* **Алгоритм обучения:** Обратное распространение ошибки (Backpropagation) и стохастический градиентный спуск (SGD).
* **Точность:** ~96-97% на тестовых данных после 10 эпох.

## 📁 Структура проекта

* `dataset.py` — загрузка, распаковка байтовых архивов MNIST и нормализация пикселей в диапазон [0.0, 1.0].
* `network.py` — математическое ядро сети: инициализация весов по методу Хе (He Init), прямой и обратный проходы, сохранение и загрузка весов.
* `train.py` — запуск обучения модели порциями (батчами по 64 картинки) и сохранение прогресса.
* `predict.py` — скрипт для распознавания твоих собственных картинок.

## 🚀 Как пользоваться

### 1. Подготовка
Убедись, что установлены необходимые библиотеки:
```bash
pip install numpy Pillow
```

### 2. Обучение сети
Запусти процесс обучения. По окончании 10 эпох прогресс автоматически сохранится в файл `weights.npz`:
```bash
python train.py
```

### 3. Распознавание своей картинки
1. Нарисуй в любом графическом редакторе цифру черным цветом на белом фоне.
2. Сохрани её как квадратное изображение под именем `digit.png` в папку проекта или укажите путь до вашего файла:
```bash
   python predict.py 2.png
```
3. Запусти скрипт распознавания:
```bash
python predict.py
```
Программа автоматически инвертирует цвета под формат MNIST, сожмет картинку до размера 28x28 и выдаст ответ с уровнем уверенности сети в процентах.
